# 六粒子两簇偏离对径的初检

Historical proof note. Equation numbers and interim questions refer to this stage of the study. See the [final theorem index](../../EVIDENCE.md) for the integrated results.

取 $N=6,L=1,\alpha=8$。令 $Y(h,t)=(0,h,2h,1/2+t,1/2+t+h,1/2+t+2h)$，另取 $X(h)=(0,h,2h,3h,4h,5h)$。两种构型的内部极小间距均为 $h$，且 $Y$ 的可行条件为 $|t|\le1/2-3h$。取 $h=263/2000$、$t=1/1000$ 时，用与手稿相同的完整周期能量和有理区间，得到
$$
E(X)-E(Y(h,0))>23/100000,\qquad E(Y(h,0))-E(Y(h,t))>1/10^8 .
$$
这在一个确定的间距下排除了对径双簇与五个连续紧间距的六粒子链的全局最优性。该次比较没有识别当时的全局最优构型，也没有证明这是随 $h$ 增加第一次失稳。

在仓库根目录将以下 Python 代码交给 Python 3 运行，可独立重做两次严格比较。

~~~python
import sys
from fractions import Fraction as Q

sys.path.insert(0, "code")
from verify_exact_clusters import certified_energy

h, t = Q(263, 2000), Q(1, 1000)
Y = [0, h, 2*h, Q(1, 2), Q(1, 2)+h, Q(1, 2)+2*h]
Z = Y[:3] + [v+t for v in Y[3:]]
X = [i*h for i in range(6)]
for cell in (X, Y, Z):
    assert all(b-a >= h for a, b in zip(cell, cell[1:]+[1]))
eX, eY, eZ = [certified_energy(cell, 8) for cell in (X, Y, Z)]
assert eX[0] - eY[1] > Q(23, 100000)
assert eY[0] - eZ[1] > Q(1, 10**8)
~~~

记 $q=e^{-\pi^2/8}$、$c=\sqrt{\pi/8}$、$T_n=2\cos(2\pi nh)-1$。记 $\kappa(h)=\partial_t^2E(Y(h,t))|_{t=0}$，则 $\kappa(h)=-(4c/6)(2\pi)^2\sum_{n\ge1}(-1)^n n^2 q^{n^2}T_n^2$。正负因子来自两个净符号相反的三粒子簇，每对相位的模方为 $2T_n^2[1-(-1)^n\cos(2\pi nt)]$。物理像和与 Fourier 求和的浮点试算均给出 $\kappa$ 在 $h\simeq0.131146805$ 附近变号。两已知候选的能量交点在 $h\simeq0.132225678$。这两个数是进一步证明的线索。

下一个可独立验收的目标是用区间界证明 $\kappa$ 在指定窄段有唯一单根，检查其他可行间距方向和四阶中心位移系数，以判定是否出现两条互为反射的偏心局部极小分支。若要认定为全局第一次转变，还须对全部六粒子可行构型建立下界或排除更早胜出的其他构型。
