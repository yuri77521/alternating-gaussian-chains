# 在三个内部宽度寻找紧双簇之外的竞争构型

Historical proof note. Equation numbers and interim questions refer to this stage of the study. See the [final theorem index](../../EVIDENCE.md) for the integrated results.

取 $L=1$。在 $s=33/4,17/2,35/4$ 各抽取七个间距下限，包括 $10^{-9}$、$1/6-10^{-8}$、两条阈值的左右和两阈值之间。对每个 $(s,h)$，按旋转和反射枚举全部 12 类非空松弛间距支撑。总计 2312 次局部搜索，得到 380 个不同的族外终点（按宽度、下限和对称轨道去重）。对每个终点，物理能量的有理下界均严格高于一个可行紧双簇的有理能量上界。

## 搜索与判号

沿用六粒子支撑面搜索的种子、整数余量和两种下降方式。在 $g_i=h+(1-6h)u_i$ 中，$u_i$ 为总和为一的非负余量。先以分母 16 在每个支撑上选种子，再以分母 $2^{20}$ 重分配余量。每个种子分别允许退到边界、以及强制每个指定的松弛间距至少留一个单位。每个搜索终点用**实际**非零的余量坐标分类。若它们多于一个且不能全部落在一对相对间距上，就属于紧双簇族外。

浮点评分用当前宽度的 $q=e^{-\pi^2/s}$，使细搜能随宽度调整方向。在紧边的比较点同样用当前宽度选取，将余量取整至分母 $2^{40}$。对每一个得出的族外点都计算完整六粒子的有向像和。只要找到一个能量严格更低的可行紧双簇，就已排除这个具体的族外点。若有重叠区间或严格低于比较点的候选，程序会立即报告坐标，须进一步与整条紧边的最小能量比较。

令 $R$ 为像半径。$0\le x_i<1$ 时，每个粒子对在任一方向的第一遗漏像距离至少为 $R$，后续距离平方的下界每次至少增加 $2R+1$。以 $e^{-v}\le 2^{-v}$ 逐项控制，整份有向能量的余项绝对值至多

$$
\frac{12\,2^{-\lfloor sR^2\rfloor}}
     {1-2^{-\lfloor s(2R+1)\rfloor}} .
$$

分子中两个方向乘以六粒子的 $36/6$ 归一化因子。对两处指数向下取整后，首项变大、几何级数的公比也变大，仍保留上界。$|p|\le R$ 的每一项用有理指数 Taylor 界计算。本次搜索取 $R=4$。在 $s=33/4,h=10^{-9}$ 的对径紧双簇上另算 $R=3,4,5$，三组能量区间依次严格嵌套。$R=3$ 时两处取整指数为 74 和 57，均来自非整数。[有理能量实现](../../code/verify_exact_clusters.py)

- 当 $h=10^{-9}$ 时，三个宽度的能差下界最小的族外搜索终点都是对径 $5+1$。相对居中的 $3+3$，其物理能差分别落在 $[98257,98258]$、$[100288,100289]$ 和 $[102205,102206]$ 乘以 $10^{-22}$ 的区间。在同一个下限把早期 $s=22$ 案例的粒子列 $(0,1/8,1/8+h,1/4,1/2,3/4)$ 延拓到这三个宽度，三次能量损失均大于 $0.22$。
- 当 $s=8.5,h=0.13$ 时，族外点 $X$ 的 $2^{20}u=(0,0,184621,0,1,863954)$ 打开了紧簇内部的一个接触。它比居中紧双簇低 $[876382134461051416,876382134461051417]\,10^{-22}$。对照偏移的紧双簇 $Y$，取其 $2^{40}u=(905905483609,0,0,193606144167,0,0)$，则 $E(X)-E(Y)\in[633494622829471,633494622829472]\,10^{-22}$。在这一参数处，15 个族外候选中有 8 个确实比居中双簇低，全部严格输给 $Y$。
- 当 $s=8.5,h=1/6-10^{-8}$ 时，族外点 $2^{20}u=(0,0,0,0,1,1048575)$ 比五接触顶点只高 $[96,97]\,10^{-22}$。目标随余量变化极小，浮点下降会在多种支撑上停下。该例说明固定绝对容差会把确实有能差的构型当成平局。

上述有理算术给出逐候选的严格比较。所有未采样的宽度、下限及构型由连续接触面证书和小间距解析论证处理。

## 复算

在仓库根目录运行以下三条命令。数值下降的分支由本机浮点舍入决定，实际抵达的终点随数学库可能略有变化。证书判号使用有理输入和整数运算，下面的关键比较亦可脱离搜索路径直接重放。

~~~sh
python -B code/probe_six_site_s9.py --width 8.25 --h .000000001 .1300211 .1300212 .131 .1322869 .1322870 49999997/300000000 --detail
python -B code/probe_six_site_s9.py --width 8.5 --h .000000001 .1289694 .1289695 .130 .1313559 .1313560 49999997/300000000 --detail
python -B code/probe_six_site_s9.py --width 8.75 --h .000000001 .1279892 .1279893 .129 .1304821 .1304822 49999997/300000000 --detail
~~~

~~~python
from fractions import Fraction as F
from math import ceil, floor
import sys
sys.path.insert(0, "code")
from probe_six_site_s9 import image_energy
from verify_exact_clusters import certified_energy

s = F(17, 2)
h = F(13, 100)
off = image_energy(h, (0, 0, 184621, 0, 1, 863954), s)
centered = image_energy(h, (1, 0, 0, 1, 0, 0), s)
shifted = image_energy(h, (905905483609, 0, 0, 193606144167, 0, 0), s)
def difference(a, b):
    return floor((a[0]-b[1])*10**22), ceil((a[1]-b[0])*10**22)
assert difference(centered, off) == (876382134461051416, 876382134461051417)
assert difference(off, shifted) == (633494622829471, 633494622829472)
h = F(1, 6) - F(1, 10**8)
assert difference(image_energy(h, (0,0,0,0,1,1048575), s),
                  image_energy(h, (1,0,0,0,0,0), s)) == (96, 97)

h = F(1, 10**9)
sites = (0, h, 2*h, F(1,2), F(1,2)+h, F(1,2)+2*h)
b3, b4, b5 = (certified_energy(sites, F(33,4), r) for r in (3,4,5))
assert b3[0] < b4[0] < b5[0] <= b5[1] < b4[1] < b3[1]
print("Intermediate-width energy comparisons and fractional-width tails passed.")
~~~
